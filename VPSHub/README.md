# VPSHub — каталог тарифов и заявки на аренду VPS

Готовый учебный проект на Python. Клиент подбирает тариф, оформляет заявку,
просматривает её и при необходимости отменяет. Менеджер работает с тарифами и заявками.
Создание виртуальных машин, подключение по SSH, списание денег и отправка email отсутствуют.
Статус «Выполнена» означает завершение обработки учебной заявки.

## Что есть в проекте

- Русскоязычный адаптивный интерфейс без сборки frontend и внешних CDN.
- Шесть демонстрационных тарифов; фильтры по названию, описанию, vCPU, RAM, диску и цене.
- Сроки аренды 1, 3, 6, 12 месяцев; стоимость считается на сервере в целых рублях.
- Выбор Ubuntu, Debian или AlmaLinux как поля заявки.
- Последние 20 открытых заявок в браузере и восстановление доступа по email + коду.
- Панель менеджера: создание и изменение тарифов, закрытие приёма заявок,
  фильтрация заказов, смена статуса и история операций.
- Снимок тарифа в заказе: изменение цены или характеристик не меняет старые заявки.
- Проверка полей на сервере, CSRF-защита форм, подписанные cookie сессии.
- SQLite для быстрого старта, PostgreSQL для задания с отдельной БД.
- Проверки `/health` и `/ready`, автоматическое создание таблиц при запуске.

## Быстрый запуск на macOS / Linux

Нужен Python 3.11 или 3.12. Команды выполняются из каталога VPSHub.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python -c 'import secrets; print(secrets.token_hex(32))'
```

Откройте `.env` и:

1. Вставьте выведенную случайную строку в `SESSION_SECRET`.
2. Задайте свой `ADMIN_PASSWORD` длиной от 12 символов. Логин по умолчанию — `manager`.
3. Для локального HTTP оставьте `COOKIE_SECURE=false`.

Значения `REPLACE_...` приложение намеренно не принимает.
Для значений с пробелами или `#` используйте кавычки по синтаксису dotenv.

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000. Панель менеджера: http://localhost:8000/admin/login.
Остановка — Ctrl+C. В локальной разработке можно добавить `--reload`.
При запуске на ВМ используйте её IP вместо `localhost`.

### Windows PowerShell

```powershell
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python -c "import secrets; print(secrets.token_hex(32))"
# Отредактируйте .env, как описано выше.
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Если политика PowerShell блокирует активацию, используйте `.venv\Scripts\python.exe`
вместо `python` в командах установки и запуска — активация тогда не нужна.

## Данные и конфигурация

| Переменная | Назначение |
| --- | --- |
| `APP_NAME` | Название панели; по умолчанию VPSHub |
| `DATABASE_URL` | SQLAlchemy URL БД; по умолчанию `sqlite:///./data/vpshub.db` |
| `SESSION_SECRET` | Случайная строка от 32 символов, обязательна |
| `ADMIN_USERNAME` | Логин единственного менеджера; по умолчанию manager |
| `ADMIN_PASSWORD` | Пароль от 12 символов, обязателен |
| `COOKIE_SECURE` | true для HTTPS; для локального HTTP — false |
| `SEED_DEMO` | true добавляет шесть тарифов, если таблица тарифов пуста |

Переменные окружения процесса имеют приоритет над `.env`.
Файл SQLite создаётся в `data/`; удаление контейнера без тома приведёт к потере этого файла.
Не добавляйте `.env`, БД и виртуальное окружение в Git или образ контейнера.
Сохраняйте один `SESSION_SECRET` между перезапусками; его смена завершает текущие сессии.
Сессия действует 8 часов. В cookie находятся служебные данные и коды недавних заявок;
cookie подписана, но не зашифрована. Имена, email и пароли туда не записываются.
Код доступа к заявке следует считать секретом. Email-подтверждения и аккаунтов клиентов нет.

### PostgreSQL

Приложение умеет работать с уже доступной PostgreSQL (например, версии 16 или 17).
Создайте БД и пользователя через администратора PostgreSQL:

```sql
CREATE ROLE vpshub LOGIN PASSWORD 'choose-a-strong-password';
CREATE DATABASE vpshub OWNER vpshub;
```

В `.env` задайте:

```dotenv
DATABASE_URL=postgresql+psycopg://vpshub:YOUR_PASSWORD@localhost:5432/vpshub
```

Специальные символы в пароле внутри URL нужно percent-encode.
В Docker Compose вместо `localhost` используйте DNS-имя сервиса БД, например `db`.
Таблицы создаются при старте; отдельной команды миграции не требуется.
Данные из SQLite в PostgreSQL автоматически не переносятся.

Первичный запуск должен выполняться одним процессом приложения: демоданные проверяются
при старте. Для задания достаточно одного worker. Масштабирование и миграции схемы —
дополнительная работа; `create_all` не обновляет структуру существующих таблиц.

## Сценарий проверки руками

1. Найдите тариф с RAM от 4 ГБ и ценой до 1000 ₽: должен остаться Standard.
2. Выберите Start, срок 3 месяца: итог — 900 ₽. Отправьте заявку.
3. Сохраните номер и код, откройте «Мои заявки».
4. В другом браузере найдите эту заявку по email и коду.
5. Войдите менеджером. Измените цену Start: старая заявка должна остаться на 900 ₽.
6. Переведите её в «В обработке», затем «Выполнена». События видны в истории.
7. Создайте другую заявку, отмените её от имени клиента.
8. Отключите тариф: он исчезнет из каталога; старые заявки сохранятся.
9. Перезапустите приложение: заявки и изменения тарифов должны сохраниться.

## Тесты

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты используют отдельные временные SQLite-файлы и не затрагивают рабочую БД.
Проверяются фильтры, расчёт цены, доступ к заявкам, отмена, переходы статусов,
снимки тарифов, валидация, CSRF, защита менеджерских страниц и сохранение данных.
Полный набор зафиксированных зависимостей проверенного окружения: `requirements-lock.txt`.
Для его воспроизведения используйте Python 3.12 и `pip install -r requirements-lock.txt`.

## Структура

- `app/main.py` — точка входа Uvicorn.
- `app/web.py` — маршруты, формы, права доступа и бизнес-правила.
- `app/config.py` — настройки из окружения и `.env`.
- `app/models.py` — таблицы тарифов, заявок и событий.
- `app/database.py` — подключение к БД, создание таблиц, демоданные.
- `app/templates/`, `app/static/` — HTML, CSS и небольшой JavaScript.
- `tests/` — интеграционные тесты.
- `docs/STUDENT_TASK.md` — задание и критерии приёмки.
- `docs/TEACHER_NOTES.md` — сценарий демонстрации и вопросы.

## Границы учебной версии

Один менеджер из переменных окружения, без регистрации и восстановления пароля.
Защиту от перебора паролей и ограничение частоты запросов следует добавить перед
публичным использованием. Внешний доступ разворачивайте через HTTPS-прокси; пароль
менеджера передаётся браузером при входе. Логи Uvicorn содержат пути запросов,
в том числе коды открываемых заявок: не публикуйте логи с такими путями.
Панель менеджера показывает до 200 последних заявок; пагинация — дополнительное задание.
Тарифы не удаляются физически, чтобы сохранялась связь с заказами.

Dockerfile, Compose и конфигурация reverse proxy намеренно не включены — их пишут студенты.
