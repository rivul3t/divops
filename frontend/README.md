# Фронтенд VPS-сервиса

Веб-панель на чистом HTML/CSS/JS (без фреймворков и сборки). Контейнер
«Веб-приложение [JS]» + «Балансировка [Nginx]» со схемы C2. В проде nginx
раздаёт статику и проксирует `/logic` на бэкенд-сервис ядра
(`tsu_vps_service`, см. [docs/API.md](../tsu_vps_service/docs/API.md)) — всё
на одном origin, поэтому CORS не нужен.

## Структура

```
frontend/
├── index.html           # разметка (вкладки, формы, таблицы)
├── css/styles.css        # стили
├── js/
│   ├── api.js            # клиент REST API (fetch-обёртка)
│   └── app.js            # логика UI
├── nginx.conf.template   # конфиг nginx (статика + прокси /logic)
└── Dockerfile            # nginx:alpine + статика
```

Манифесты k3s для всего стека (фронт + бэкенд + postgres) лежат в `../k8s/`.

## 1. Локальная разработка (без Docker)

Любой статический сервер:

```bash
cd frontend
python3 -m http.server 3000      # → http://localhost:3000
```

По умолчанию фронт стучит на **тот же origin** (`/logic/...`), поэтому без
nginx напрямую к ядру он не достучится. Для разработки впиши адрес ядра в поле
«API» в шапке, например `http://localhost:8080` (тогда ядру нужен CORS).

## 2. Docker-образ (nginx + статика)

```bash
cd frontend
docker build -t vpshub-frontend:0.1.0 .
```

Конфигурируется через env (значения по умолчанию — в `Dockerfile`):

| Переменная | Назначение | Пример |
|---|---|---|
| `BACKEND_HOST` | адрес бэкенда для прокси `/logic` | `tsu-vps-service:8080` |
| `DNS_RESOLVER` | DNS для рантайм-резолва имени бэкенда | `10.43.0.10` (k3s), `127.0.0.11` (compose) |

Локальная проверка (отдаёт статику; `/logic` заработает, когда поднимешь бэкенд):

```bash
docker run --rm -p 8080:80 -e DNS_RESOLVER=127.0.0.11 vpshub-frontend:0.1.0
# → http://localhost:8080
```

## 3. Деплой в k3s

Весь стек (фронт + бэкенд + postgres) деплоится из `../k8s/` — там манифесты,
доставка образов и команды. Образ фронта (`vpshub-frontend:0.1.0`) в кубере
смотрит на бэкенд через `BACKEND_HOST=backend:8080`.

## Что умеет панель

| Раздел | Действия |
|---|---|
| Пользователи | список, создание (email / пароль / роль) |
| Тарифы | список, создание, редактирование (PUT), удаление |
| Виртуалки | список, создание (пользователь и тариф из выпадашек), удаление |
