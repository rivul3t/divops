## 1. Цель и границы

Какой сервис вводим в эксплуатацию: веб-панель управления VPS
Какие результаты обеспечивает команда: работающая панель на стенде, сценарий развёртывания, резервные копии и проверенное восстановление, мониторинг, инструкции.
Что предоставляется преподавателем/заказчиком: учебный стенд
Что пока не входит в учебную реализацию: платежка, настоящие виртуальные машины (вместо них контейнеры), перенос VPS между хостами, резервные копии содержимого VPS клиентов.

## 3. Требования и проверки

| ID | Тип | Требование и условия | Способ проверки | Статус/источник |
|---|---|---|---|---|
| F-01 | Функциональное | Клиент входит в панель по логину и паролю | Войти тестовым клиентом с верным и неверным паролем | Факт |
| F-02 | Функциональное | Клиент создаёт VPS, выбирая тариф | Создать VPS, проверить, что он запущен и имеет ресурсы тарифа | Факт |
| F-03 | Функциональное | Клиент видит список своих VPS и их статус | Создать 2 VPS, остановить один, проверить статусы в списке | Факт |
| F-04 | Функциональное | Клиент запускает, останавливает и перезагружает VPS | Выполнить каждое действие, проверить статус VPS | Факт |
| F-05 | Функциональное | Клиент удаляет VPS | Удалить VPS, проверить, что он пропал из списка и с хоста | Факт |
| F-06 | Функциональное | Клиент видит график загрузки CPU и RAM своего VPS | Нагрузить VPS, проверить, что график вырос | Допущение |
| N-01 | Нефункциональное | Данные о клиентах и VPS сохраняются после пересоздания панели | Создать VPS, пересоздать контейнер панели, проверить список | Факт |
| N-02 | Нефункциональное | Список VPS открывается с p95 ≤ 500 мс при расчётной нагрузке | Нагрузочный тест | Допущение |
| N-03 | Нефункциональное | VPS создаётся не дольше 2 минут | Создать 5 VPS, засечь время каждого | Допущение |
| N-04 | Нефункциональное | При потере сервера с БД панели RTO ≤ 30 мин, RPO ≤ 1 ч; копии хранятся отдельно | Учебный отказ, восстановиться из копии, засечь время | Допущение |
| N-05 | Нефункциональное | Клиент видит и управляет только своими VPS | Запросить действие с чужим VPS, ожидать отказ | Факт |
| N-06 | Нефункциональное | Нельзя создать VPS сверх квоты тарифа | Превысить квоту, ожидать отказ | Допущение |
| N-07 | Нефункциональное | Падение панели не останавливает уже работающие VPS | Остановить панель, проверить, что VPS продолжают работать | Допущение |
| N-08 | Нефункциональное | БД недоступна снаружи, открыт только порт панели | Подключиться к порту БД с внешней машины, ожидать отказ | Допущение |
| O-01 | Ограничение | В учебной реализации VPS — это контейнеры на одном хосте | — | Факт |

Исходное ожидание по сохранности данных: данные клиентов и их VPS не теряются при сбоях.
Согласованное ограничение учебного стенда: RPO <= 1 ч, RTO <= 30 мин.
Сценарий отказа, для которого заданы RTO и RPO: потеря сервера с базой данных панели.
